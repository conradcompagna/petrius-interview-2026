# PetrIUS interview package

**For the advance written submission, download `Task_I_written_submission.zip`.** It contains the completed small program, reference labels, coloured overlays, confusion matrix, detailed outputs, MDZ addresses and two-page note. Task II is a separate document.

The source archive contains the Task I program, local viewer, model inference code, two-page note, slide deck and speaking script. The seven `assets-*.zip` archives contain the page images, annotations, experiment outputs and selected model weights.

**Installation:** extract the source archive first, then extract every asset ZIP into that same folder. The resulting `models/` and `viewer_data/` directories must sit beside `README.md`. Each ZIP extracts normally; there is no multipart archive to join. The seven asset archives total 4.13 GB.

Install Python 3.12, then open `RUN_VIEWER.bat` to inspect the results, `task1_min/run.bat` to reproduce the assigned two-page solution, or `inference/setup.bat` followed by `inference/run.bat` to run the trained pipeline. All model weights are included. `GET_ASSETS.bat` downloads and verifies the assets automatically for an authenticated private clone.

The Task I program reproduces all 131 reference decisions and includes the gutter numbers and woodcut initial. The viewer opens on the finished datasets and results, with earlier experiments in a collapsed menu. The fifteen-minute presentation covers Tasks I, III and IV; Task II is being prepared separately by the author.

`SHA256SUMS.txt` records the archive hashes. `docs/release_assets.json` records the hash of every member. All ZIPs passed CRC checks and every archived file was verified against its source.

The repository and release remain private. The GitHub Pages viewer is prepared for the author's later public release.
